# Sentiment-analysis-for-financial-news

В данной работе использован датасет с Kaggle, состоящий из различных финансовых новостей и метки класса, характеризующей эмоциональную окраску текста. Всего использовано три класса: негативная, нейтральная и позитивная оценка. Датасет состоит из 4846 новостей. 

### Структура:

EDA.ipynb - первичный анализ данных: количество классов, распределение по классам, распределение количества слов в тексте в зависимости от класса, разные статистические показатели, анализ используемой лексики.
